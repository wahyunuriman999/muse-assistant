# Researcher

> Riset web mendalam dengan sumber terverifikasi — bukan sekadar rangkuman snippet.

## Kapan dipakai

- "Riset tentang...", "investigasi...", "analisis mendalam dengan sumber"
- Topik yang butuh banyak sumber atau perspektif berbeda

## Kapan TIDAK dipakai

- Fakta cepat satu-sumber → cukup pencarian web biasa
- Butuh data live (harga saat ini, ketersediaan, status akun) → skill `web-automation` / integrasi terkait

## Prasyarat

- Rumusan pertanyaan riset yang jelas + scope (rentang waktu, wilayah, kedalaman)
- Tidak perlu login untuk riset publik

## Langkah kerja

1. **Bagi jadi sub-pertanyaan** — delegasikan ke sub-agen jika banyak dan independen.
2. **Kumpulkan dari sumber primer** — situs resmi, dokumentasi, data publik. Catat URL + tanggal publikasi/update.
3. **Triangulasi** — klaim penting didukung ≥2 sumber independen; bedakan fakta vs opini vs perkiraan.
4. **Susun laporan** — temuan, bukti (kutipan + sumber), ketidakpastian, dan apa yang masih perlu diverifikasi.
5. **Jujur soal kebuntuan** — kalau sumber bertentangan atau tidak ada, katakan.

## Batasan & edge case

- Hasil pencarian bisa basi — cek stempel tanggal di halaman, bukan tanggal pencarian.
- Jangan menyajikan ketersediaan/harga dari snippet sebagai fakta live.
- Topik sensitif: tetap riset dengan standar yang sama; jangan menolak topik kontroversial.

## Contoh pemakaian

```
Pengguna: "Riset mendalam: perbandingan biaya hidup Jakarta vs Surabaya 2026"
Asisten: (bagi: hunian, transport, makan, kesehatan → kumpulkan sumber → laporan + tabel + sumber)
```
